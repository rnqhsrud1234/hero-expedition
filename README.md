```sh

npm run build
npm run preview
```

## 현재 한계와 다음 작업

`src/migrated/`는 AST로 원본을 분리한 **임시 호환 계층**입니다. 공유 레지스트리와 동적 타입, 기존 전투 규칙의 래퍼 연결이 남아 있습니다. 게임을 새로 기획하지 않고 규칙을 비교하기 위한 중간 단계이며, 명세서의 최종 구조를 충족한 것으로 간주하지 않습니다.

1. 호환 계층을 명시적인 Player/Enemy/Skill/Combat/Reward 시스템으로 교체하고 비교 테스트 유지
2. 남은 전투 수치를 데이터 파일로 추출하고 전투 엔티티 풀링 적용 (현재 재사용은 렌더링 객체 중심)
3. 장비·상점·성장·결과 DOM 모달을 Phaser UI로 교체
4. 모든 성장 카드의 실제 수치 미리보기, 상태 아이콘, 캐릭터 상태별 프레임 애니메이션 확장
5. 던전·몬스터·보스 아트 및 패턴 개선, 실제 플레이 기반 밸런스 검증
6. 실제 브라우저/WebGL/모바일 터치·안전영역·성능 검증
7. 인증된 Vercel 환경에서 테스트 URL 배포, 웹 안정화 후 Capacitor APK

원본에는 공통 마나 자원이 없으므로 이 단계에서 임의로 추가하지 않았습니다. BGM 채널은 준비되었지만 배경 음악 자산은 추가하지 않았습니다. 그래픽 변환기는 일부 그라데이션·그림자·점선을 단순화합니다.

## 검증 범위

- `tests/parity.mjs`: 고정 시드와 시간으로 원본/이식 규칙 비교. 57개 기술, 85개 성장 카드, 장비 생성, 8개 이벤트, 3개 보스 시뮬레이션.
- `tests/native-render.mjs`: 실제 Phaser CanvasRenderer를 오프라인 DOM 모형에서 실행. 5영웅·57기술, 던전/엘리트/보스/성장/보상/로비 흐름, 저장 왕복 확인.
- 흐름 테스트는 빠른 검증을 위해 적에게 높은 피해를 적용합니다. 정상 DPS나 보스전 시간 검증이 아닙니다.
- 오프라인 테스트는 실제 브라우저, WebGL, 모바일 기기, 생산용 부팅 로더의 검증을 대체하지 않습니다.
- `qa/`에 JSON 결과와 오프라인 렌더 이미지, `docs/source-map.json`에 원본 위치 대응표가 있습니다.

기존 규칙 일치 테스트는 신규 자동 공격, 강공격 정지 등 화면/입력 연결부의 동작까지 동일하다는 의미가 아닙니다.
